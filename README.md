# Secret Santa del Branco e del Cerchio

App web per il Secret Santa (3–9 persone): sorteggio con esclusioni, una sola apertura per persona,
elenco pubblico di chi ha pescato, preferenze, conto alla rovescia, inviti WhatsApp, area admin.

Due file:
- `Code.gs` → backend (Google Apps Script)
- `index.html` → sito (GitHub Pages)

## 3. Uso
1. Apri il sito → **Area Akela** → password → inserisci partecipanti, esclusioni, data/luogo → **Crea il sorteggio**.
2. In «Tutti i segreti» premi **WhatsApp** accanto a ogni nome: il messaggio contiene il link personale.
3. Ogni persona apre il link, (facoltativo) scrive 3 preferenze, apre il bigliettino **una sola volta**.
4. Se qualcuno perde il suo abbinamento: Area Akela → leggi l'abbinamento o premi **Riapri**.
